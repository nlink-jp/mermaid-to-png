# mermaid-to-png

[日本語](README.ja.md)

Turn one mermaid diagram into one PNG, locally and with no browser.
`mermaid-to-png` is a command-line front end to
[mermaid-render](https://github.com/nlink-jp/mermaid-render), the
organization's own mermaid engine.

> Under development. Usage and installation will be written here with the
> first release.

## Installation

```bash
make build    # → dist/mermaid-to-png
```
